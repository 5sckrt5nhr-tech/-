ПО БАРАБАНУ — демонстраційний сайт
===================================

Файли:
- index.html — структура сайту
- style.css — оформлення та адаптивність
- script.js — меню, FAQ та демонстраційна форма

Як переглянути:
1. Розпакуй архів.
2. Відкрий index.html у браузері.

Як опублікувати через GitHub Pages:
1. Створи публічний репозиторій з назвою po-barabanu.
2. Завантаж УСІ файли з цієї папки в корінь репозиторію.
3. Settings → Pages → Deploy from a branch.
4. Branch: main; Folder: /(root); Save.
5. Після публікації GitHub покаже адресу сайту.

Перед реальною публікацією:
- заміни позначення локації та додай справжні контакти;
- уточни реальні ціни, тривалість сеансів і кількість учасників;
- підключи форму бронювання до сервісу/бекенду: зараз вона демонстраційна;
- перевір права на використання фотографій із зовнішніх джерел.
